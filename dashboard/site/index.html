Legend

    PR is the latest build.yml run for a pull request targeting the branch. Release is the latest upload.yml run on the branch (pack, optional tests, Store upload). Setup failed means the job broke before sdkcraft pack (runner, LXD or sdkcraft install). Didn't start (startup_failure) usually means an invalid or inaccessible workflow; needs approval (action_required) usually means the PR was authored by github-actions[bot] instead of the Renovate app.
